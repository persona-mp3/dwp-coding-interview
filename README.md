## Cinema Tickets Application
To run the application, make sure you have at least java 21 installed.

## The task
The task can be found at [Task.md](./cinema-tickets-java/Task.md)


## Pre-requsites
- Java 21 or above
- pre-commit 

### Clone the repository 
```bash 
git clone https://github.com/persona-mp3/dwp-coding-interview.git dwp-coding-interview 
```

### Access the working directory
```bash
cd dwp-coding-interview/cinema-tickets-java
```

### Run tests
```bash
mvn test
```
